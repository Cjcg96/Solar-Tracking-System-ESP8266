# Intelligent Solar Tracking System – ESP8266 & MATLAB

## Project Overview

Development of a dual-axis solar tracking prototype using an ESP8266 NodeMCU microcontroller, four LDR light sensors, an analog multiplexer, and servomotors.

The system is designed to adjust the orientation of a solar panel according to light intensity measurements.

## Technologies Used

- **Microcontroller:** ESP8266 NodeMCU
- **Programming:** Arduino IDE (C/C++)
- **Sensors:** Four LDR light sensors
- **Analog Multiplexer:** HC4067
- **Actuators:** Two servomotors
- **IoT Platform:** ThingSpeak
- **Data Analysis:** MATLAB

## Main Features

- Acquisition of light intensity measurements
- Dual-axis solar panel positioning
- Servomotor control based on sensor differences
- IoT-based monitoring through ThingSpeak
- MATLAB scripts for electrical data visualization and analysis
- Monitoring of voltage, current, power, tilt angle, and rotation angle

## Engineering Skills Demonstrated

Embedded systems, electronic circuits, sensor integration, control systems, microcontroller programming, MATLAB, and IoT data acquisition.
